# Static Graphics / Posters / Cards / Covers

Use this reference for posters, banners, social cards, covers, event announcements, invitations, promotional graphics, and print artwork. Read the entire `references/original-art-direction.md` first; it is the primary art-direction specification.

## Define the deliverable

Determine whether the user needs a finished raster image, editable SVG/HTML/CSS, print-ready document, reusable template, or concept description. Do not substitute a flattened image when editable structure is required, and do not present an image prompt as if it were a finished design. Use an image generator when an image is requested and one is available. When text must be pixel-accurate or content is dynamic, put typography into deterministic layout tooling where possible.

## Concept and art direction

Establish the specific message and audience. Choose a semantic metaphor or another idea that survives the interchangeability test. Do not confuse the concept with the art style. Evaluate the idea before choosing photography, 2D illustration, collage, typography, 3D, print, or a hybrid technique. Avoid generic industry icons without justification: code on monitors for IT, light bulbs for ideas, random chrome, particles, or neon as shorthand for "technology."

## Production brief

Before rendering, specify aspect ratio, safe margins, likely cropping, the main subject and its approximate share of the frame, eye movement, headline placement, supporting copy, negative space, primary contrast, intended distribution or printing method, and exact visible text. Do not invent advertising claims, contact details, prices, testimonials, or logos that are absent from the source. Treat spatial instructions as likelihood-improving guidance, not pixel coordinates for a probabilistic generator.

## Text, photography, and external assets

All visible text must match the requested copy verbatim, or an explicitly requested revision. Do not allow extra captions, watermarks, invented marks, or random symbols. For text-heavy or legally exact material, separate image creation from typographic layout when possible. Preserve the recognizable appearance of any person shown in user-supplied photographs. When using external assets, consider licenses, attribution, provenance, and technical quality; do not substitute unrelated stock imagery for supplied references. Preserve the language and locale established by the user or project.

## Inspect the artifact

Assess first-glance hierarchy, readability at the intended display size, exact wording, factual accuracy, physically plausible object interactions, fingers and limbs, perspective, compositional noise, and visible artifacts. Check cropping safety, dimensions, file format, and transparency when relevant. Correct defects by changing the instructions that caused them; when the result is generic, replace the semantic mechanism rather than simply recoloring it. If the final render was not actually generated and inspected, state that limitation rather than implying otherwise.
